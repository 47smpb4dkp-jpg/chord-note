# コード譜ノート

弾き語り用のコード譜アプリ。iPad のホーム画面に置いて使う。

## このフォルダの中身

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体。これ1つで全部動く |
| `manifest.json` | ホーム画面に置いたときの名前とアイコンの設定 |
| `sw.js` | オフラインでも開けるようにする仕組み |
| `icon-*.png` | アイコン |
| `start-local.ps1` | このパソコンで動かすための簡易サーバー |

## このパソコンで動かす

`start-local.ps1` を右クリック →「PowerShell で実行」。
ブラウザが自動で開く。終わるときはその黒い窓で Ctrl+C。

PowerShell から実行する場合:

```powershell
cd $HOME\apps\chord-note
.\start-local.ps1
```

実行がブロックされたら、一度だけこれを打つ:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

## iPad で使う

ここが本番。**マイクを使うには HTTPS が必要**で、`http://192.168...` のような
LAN 経由では Safari がマイクをブロックする。そのため置き場所が要る。

### GitHub Pages に置く（無料・HTTPS付き）

1. github.com でアカウントを作る
2. 新しいリポジトリを作る（Public）
3. このフォルダの中身を全部アップロードする
4. Settings → Pages → Source を `main` ブランチにして保存
5. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

### ホーム画面に追加する

iPad の Safari でそのURLを開き、共有ボタン →「ホーム画面に追加」。
これでアドレスバーの無い全画面で起動し、見た目はアプリと変わらない。

## 使い方

**フッターの4つのタブ**

- 楽曲リスト … 登録した曲。お気に入り / よく使う / フォルダで絞り込める
- プレイリスト … 演奏順。本番用のセットリスト
- 新規登録 … 曲を作る。音から / ファイルから の2通り
- コード … 押さえ方。ルート音と種類を選ぶ

**原曲キーとカポ**

新規登録では、原曲キーとカポを**ボタンで選ぶ**。
メジャー12個・マイナー12個・指定なし、カポは なし〜12。
コード譜を貼り付けるとキーを自動で推測し、そのボタンが選ばれた状態になる。違えば押し直せばよい。

**曲を作る3つの入口**

1. マイクで録音 → コード進行・キー・テンポを自動で解析
2. 音源ファイルを読み込む → 同じ解析をかける
3. コード譜ファイルを取り込む（.md / .txt / .docx / .pdf / 画像、フォルダごと可）

**ファイルの読み取りについて**

| 形式 | 読み方 | 精度 |
|---|---|---|
| .zip | 中を開いて、下の形式のファイルを取り出す | 中身しだい |
| .md / .txt | そのまま | 確実 |
| .doc | OLE2を展開して本文を取り出す（旧Word） | 確実。全角スペースの桁も保たれる |
| .docx | ZIPを展開して段落を取り出す | 確実 |
| .pdf | 文字の情報を位置ごと取り出す | 文字情報があれば確実。画像として作られたPDFは読めない |
| | ↑ 初回だけ読み取り部品をネットから取りに行く。圏外では読めない | |
| 画像 | 背景色を判定して白地に揃えてから文字を読む | 間違いが混ざる。必ず確認すること |

画像の読み取りは初回だけ日本語の辞書をダウンロードするので時間がかかる。2回目からは速い。

**読めるコードの書き方**

次はどれも1つのコードとして読む。書いたとおりの文字で表示され、移調しても形は崩れない。

| 書き方 | 読み方 |
|---|---|
| `C／` `D//` `Bm//` | 拍の印つき。スラッシュはそのまま出る |
| `ConG` `C(onG)` `C on G` | 分数コード（`C/G` と同じ） |
| `FonC／` `B♭onD／` | 分数コード＋拍の印 |
| `B♭m7` `A♭add9` `E♭` | ♭ は ♭ のまま |
| `F＃` `D＃m` | 全角の ＃ も読む |
| `G7(#9)` `Dm7-5` `G7sus4` | 括弧つき・テンションつき |
| `（ Am G F E ）` | 行ぜんたいを括弧でくくったコード行 |

**ZIP の読み込み**

ZIP を選ぶか、ドラッグすると中を開いて、フォルダごと読み込んだときと同じ一覧に並べる。

- 中のフォルダ名がそのままジャンルになる
- 読めない形式（音声・動画・Excel など）は黙って飛ばす
- Mac で作った ZIP に混ざる `__MACOSX` や `.DS_Store` も飛ばす
- 壊れている ZIP やパスワード付きの ZIP は、その理由を一覧に出す

書き出した ZIP をそのまま読み込み直せる。

**前後の曲へめくる**

曲を開いたら、画面上の**曲名のところを左右にスワイプ**すると前後の曲へ移動する。
左へはらうと次の曲、右へはらうと前の曲。曲名の右にある **‹ ›** ボタンでも同じ。
パソコンなら **← →** キーでもめくれる。

順番は「その曲をどこから開いたか」で決まる。

| 開いた場所 | めくる順番 |
|---|---|
| 楽曲リスト | そのとき画面に出ていた並び（絞り込み・分類をそのまま使う） |
| プレイリスト | そのセットリストに並べた演奏順 |

曲名の下に「3 / 12 · ライブ用」のように、いま何曲目かが出る。
縦になぞったときは動かないので、譜面のスクロールとはぶつからない。

**同じ曲の別バージョン**

同じ曲でも、作った時期やアレンジでコード進行や歌詞が違うものを「バージョン」として分けて持てる。
女性キー版・男性キー版のように、キーとカポも**バージョンごとに別々に覚える**。

- 楽曲リストでは**1行にまとまり**、曲名の横に「3バージョン」と出る
- 曲を開くと、キーやテンポの下に**バージョンの切り替えボタン**が並ぶ。押すと切り替わる
- 切り替えても前後の曲へのスワイプは効く（めくるのは曲単位で、バージョンは飛ばさない）

作り方は2通り。

| やり方 | 場所 |
|---|---|
| いまの譜面を直して別バージョンにする | 曲画面 →「編集」→ **別バージョンで保存**。名前を聞かれる |
| ファイルから取り込む | 同じ曲名があると、取り込み一覧に選択肢が出る |

取り込みのときは、**曲名が同じかどうか**でまず引っかけて、**歌詞がどれくらい同じか**を数字で出す。
コード行・空白・記号は外して歌詞の文字だけを比べるので、改行の位置が違っても正しく比べられる。

| 一致率 | 出る案内 | 初期の選択 |
|---|---|---|
| 70%以上 | 歌詞はほぼ同じ | 別バージョンとして足す |
| 30〜70% | 歌詞の一部が同じ | 別バージョンとして足す |
| 30%未満 | 曲名は同じだが歌詞はかなり違う | 別の曲として入れる |

どれを選ぶかは毎回自分で決められる。「別バージョン / 上書き / 別の曲」の3つから選ぶ。
判定が外れても、押し直せばいいだけ。

バージョン名を付けずに別バージョンを作ると「バージョン2」のような仮の名前が入る。
あとから「編集」の**バージョン名**の欄で変えられる。
元からあったほうには自動で「もとの版」と名前が付く。

書き出すと `曲名 - バージョン名.md` というファイル名になり、中身にも `version:` の行が入る。
読み込み直せばバージョン名もそのまま戻る。曲を選んで書き出すと、そのバージョン違いも一緒に出る。

**曲を直す**

曲画面の「編集」から、本文・曲名・キー・カポ・BPM・1行の小節数をまとめて直せる。
ヘッダーの保存ボタンは2つ。**上書き保存**はいま見ているバージョンを書き換える。
**別バージョンで保存**は元を残したまま新しいバージョンとして足す。

左の「コード譜」と右の「表示の確認」は、**同じ文字・同じ桁・同じ行の高さ**で出している。
確認側は譜面を組み直さず、入力した文字をそのまま並べてコードだけ色を付ける。
だから1行ずつぴったり対応し、縦も横もスクロールが連動する。

コード名は書いたとおりに出る。`Dm/`（拍の印）、`D//`、`B♭m7`（♭のまま）、
`A7(#9)`、`C(onG)` は、どれも入力欄と確認側で1文字も変わらない。
移調しても拍の印と ♭ 表記は保たれる。
直した結果はその場で下に表示される。一番下に削除もある。

演奏中に変えたスクロール速度・カポ・移調は、そのまま曲に記録される。次に開くとその状態から始まる。

**分類のしかた**

分け方が3つあり、役割が別々になっている。

| | 性質 | 使い道 |
|---|---|---|
| ジャンル | 1曲に1つ | オリジナル・フォーク・ロックなど。曲の置き場所 |
| アーティスト | 1曲に1つ | 作曲者・バンド。楽曲リストのタブで切り替えて分類できる |
| セットリスト | 1曲が複数に入れる | 演奏順。ライブ用・リハ用 |

**まとめて操作する**

楽曲リストの「選択」から、何曲か選んでまとめて削除・フォルダ移動・プレイリスト追加ができる。

**フォルダから一括で取り込む**

新規登録の「フォルダから一括読み込み」でフォルダごと読む。一覧が出たら、

1. 各行の「中身を見る」で1曲ずつ直す。直した内容は一覧に残る（「直した」の印が付く）
2. ジャンルをまとめて変える
3. 取り込む曲にチェックを入れて「選んだ曲を取り込む」

この順で、全部直してから一度に楽曲リストへ入る。

**コードとして読まれない行**

行の先頭に `@` を付けると、その行は必ずコード行になる。画像からの読み取りで崩れた行や、演奏指示の混ざった行に使う。`@` 自体は表示されない。

ただし手で打つ必要はない。**編集画面の「表示の確認」側で、行の左のボタンを押せば切り替わる。**

- `♪` … その行は今コード行。押すと歌詞行に戻る
- `＋` … その行は今歌詞行。押すとコード行になる
- `＋` が色付きのときは、コードらしい語が入っている行。直す候補

広い画面では本文と確認が左右に並び、狭い画面では上下に並んで連動してスクロールする。

**分数コードの書き方**

次はすべて同じものとして読む。表示は書いたままの形で残り、移調するとベース音も一緒に動く。

- `D/F#`
- `ConG`
- `C on G`
- `C(onG)` / `Dm7(onF)`
- `D/` `D//` … 後ろに音名が続かないスラッシュは拍の印。`D` として読む

**狭い画面での折り返し**

コードと、その下にくる歌詞の一部分を1組にして並べている。画面が狭いときは組ごと折り返すので、
コード行と歌詞行がずれることがない。横スクロールは起きない。

長い歌詞は日本語の折り返しのきまりに従って自然な位置で改行する。
コードだけの行は、元の間隔が広くても一定の幅で抑えるので、横に飛び出さない。

**太字と細字の違い**

コード譜の中で、太いオレンジはコードとして読めたもの。移調もされるし、押すと押さえ方が出る。
細い字は、コード行の中にあるがコード名として読めなかった語。注記として置いてあるだけで移調されない。
細い字が残っていたら、読み違いか、対応していない書き方。

空行はそのまま残るので、Aメロ・Bメロの区切りに使える。

**共有する**

曲画面の「共有」で1曲、楽曲リストの下から全体の共有リンクを作れる。
相手はログインなしで見られ、自分の画面で移調やカポを変えられる。編集はできない。
リンクを知っている人は誰でも見られるので、扱いに注意すること。音源は共有されない。
止めるときは楽曲リストの「共有中のリンク」から。

**演奏中**

- コード名をタップ → 押さえ方が出る
- スライダーで BPM を変える → 自動スクロールの速さが変わる
- 左右に大きくスワイプ → プレイリストの前後の曲へ
- 上下にスワイプ → 手動で位置を調整（自動スクロールは一旦止まる）

## 「保存容量がいっぱいです」と出たとき

譜面は消えていない。ブラウザがこのページに割り当てた保存場所が埋まっただけ。
**楽曲リストの一番下 →「端末の空き容量を見る」**から片付ける。

| 置いてあるもの | 消すとどうなる |
|---|---|
| 曲に付けた音源 | 譜面は残る。元のファイルがあれば付け直せる。**いちばん場所を取るのはこれ** |
| オフライン用の控え | クラウド側の譜面は消えない。次にネットにつないだとき取り直す |

音源はこの端末にだけ置かれ、ほかの端末には同期されない。
曲を消しても音源だけ残ることがあるので、「いらない音源だけ外す」で拾える。

**容量のエラーが何をしても直らないとき**は、「書き込めるか調べる」を押す。
1MB の書き込みを実際に試して、端末そのものが書けない状態なのかを判定する。

- 「できなかった」→ **パソコンの空きディスクが足りない。** ブラウザの上限に届いていなくても、
  ディスク自体が少ないと書けない。パソコン側を空ける
- 「できた」→ 控えが大きくなりすぎている。控えを捨てるか、使わない設定にする

**最後の逃げ道**が「控えを使わない設定にする」。
この端末に控えを置かなくなるので、**容量のエラーは出なくなる**。
そのかわり圏外では譜面を開けない（ネットにつながっていれば今までどおり）。
あとから「控えを使う設定に戻す」で元に戻せる。

「オフライン用の控え」は、圏外でも譜面を開けるようにクラウドの内容をこの端末にも置いてあるぶん。
捨ててもクラウド側は無事で、次にネットにつなげば降りてくる。

**このページをほかのタブでも開いていると控えを捨てられない。**
その場合は理由を画面に出すので（勝手に消えない・コピーできる）、
ほかのタブを閉じてからもう一度押す。

それでも足りなければ、ブラウザの設定からこのサイトのデータを消したうえで、
ログインし直せばクラウドから全部降りてくる（音源は降りてこない）。

| | どこ | 役割 |
|---|---|---|
| Firebase Firestore | Google のデータベース（プロジェクト `chord-note-f916e`） | **主役。** 端末どうしを揃える |

## 保存先について（よくある疑問）

| | どこ |
|---|---|
| 譜面データ | **Firebase Firestore**（Google のデータベース）。プロジェクト `chord-note-f916e`。ログインした Google アカウントの下 |
| オフライン用の控え | **ブラウザの中**。フォルダではない。Chrome が site data として持つ |
| 音源 | ブラウザの中（この端末だけ。同期しない） |
| 書き出した .md | 自分で選んだ保存先（ダウンロードフォルダなど） |

**Google ドライブではない。** Firestore は Google のサービスだが、ドライブとは別物で、
フォルダとして見ることはできない。

**「上限」はブラウザが決めた枠。** Chrome は空きディスクの一定割合をサイト全体に割り当て、
そこから各サイトに配分する。**こちらで指定できない**し、フォルダを指定することもできない。
ウェブページは原則として任意のフォルダに書き込めないため。

## キーとカポの関係

**カポは、鳴る音を変えずに押さえ方だけを変える道具。**
原曲が F だとバレーがきつい。そこで3カポにして D の形で押さえる。鳴るのは F のまま。

曲画面の **Key** は鳴る音。**カポを動かしても Key は変わらない**。
変わるのは譜面のコード（＝押さえる形）のほう。

```
Key F ／ カポ 3    押さえ方 D → 鳴る音 F
   カポを 5 にすると   →  譜面が C G Am F に変わる（鳴る音は F のまま）
   カポを 0 にすると   →  譜面が F C Dm B♭ に変わる（同上）
```

最初に取り込んだときのカポが「この譜面は何カポ用か」の基準になる。
そこから動かしたぶんだけ、コードが上下する。元のカポに戻せば譜面も元どおり。

**カポを選ぶ** ボタンで、0〜12 の各位置と、そのとき押さえる形が一覧で出る。
C・G・D・A・E・Am・Em・Dm になる位置には「押さえやすい」と出る。
F の曲なら カポ1（E）、カポ3（D）、カポ5（C）、カポ8（A）、カポ10（G）が候補。

譜面を鳴る音の方で書いている場合は、編集画面の
「**この譜面に書いてあるコードは**」で切り替えられる（曲ごと）。

**Key の −／＋（移調）はカポとは別物。** こちらは鳴る音そのものを変える。
両方使うと、移調したぶんとカポのぶんが足し合わされる。

♭ の出し方は押さえ方のキーに合わせる。F のキーなら `A#` ではなく `B♭` と出る。
全角の `＃`（`C＃` `F＃`）もちゃんと音名として読む。書いた字のまま返すので、
`F＃` を2つ上げれば `G＃`。

## 同じ曲が別々に入ってしまったとき

誤字や表記ゆれで同じ曲が2つ3つに分かれてしまったら、あとから1つにまとめられる。

1. 楽曲リストで「選択」→ まとめたい曲にチェック（2曲以上）
2. 「**バージョンにまとめる**」を押す
3. どれを「もとの版」にするか選ぶ。ほかはその別バージョンになる
4. それぞれにバージョン名を付けられる（空なら自動で付く）

選ぶ画面には**歌詞の一致率**が出るので、本当に同じ曲か確かめてから決められる。
曲名は「もとの版」に合わせる。譜面・キー・カポはどれも消えず、そのまま残る。
バージョン違いを持っている曲を選ぶと、その中身も一緒にまとまる。

## 編集画面と新規登録

**2つは同じ作り**にしてある。どちらも次の順。

1. 曲名・アーティスト・ジャンル
2. **キーとカポ**（ボタンで選ぶ。打ち込みではない）
3. コードを入れる / メモを入れる
4. 左「コード譜」｜右「表示の確認」（同じ文字・同じ桁・スクロール連動）

**カポを選ぶと、コード譜の文字そのものが書き換わる。**
F#m の曲でカポ2を選べば譜面が Em になる。カポ0に戻せば F#m に戻る。
桁（コードの位置）は保たれ、歌詞・メモ・セクション名は動かない。

「コード譜に書くのは」で **押さえる形 / 鳴る音** を切り替えると、文字もその向きに書き換わる。

キーのボタンは**鳴る音**のキー。こちらを変えても譜面の文字は動かない（曲の情報だけ）。

編集画面で直したキー・カポ・コード譜は、**「← 戻る」で元に戻る**。残すには保存を押す。

## コードの押さえ方

1つのコードにつき、基本の形だけを出す。

| 出す形 | |
|---|---|
| 開放弦を使う形 | あれば必ず先頭 |
| 6弦ルート | E型を動かしたもの |
| 5弦ルート | A型を動かしたもの |
| 4弦ルート | D型を動かしたもの |

**押さえられない形は載せない。** 指が4フレット以上開くもの、
指が5本要るもの、12フレットより高いものは外してある。
そのため、コードによっては3つしか出ないこともある（開放弦の形が無い F など）。

## 楽曲リストの選択

ジャンルの見出しに3つボタンがある。

- **このジャンルを選択** … そのジャンルの曲をまとめて選ぶ（選択モードに入る）
- **解除** … そのジャンルの選択だけ外す
- **書き出す** … そのジャンルを zip で書き出す

## メモを入れる

編集画面の「**メモを入れる**」から、コード譜の**カーソルのところ**に差し込める。
よく使う言葉（2回し・くりかえし・女性キー・半音下げ…）はボタンで一発。

```
C        G        （ここだけ2回し） Am       F
```

- **コード行の途中**に入れても、その行はコード行のまま読まれる
- **何もない行**に入れればメモだけの行になる
- 括弧で囲んで入るので、コードとして読まれることはない
- 移調してもカポを変えてもメモは動かない（コードだけ動く）

バンド編成違い・女性キー版・間奏の回し数など、バージョンごとの演奏メモに使う。
バージョン機能と組み合わせると、同じ曲の違いが譜面の中で分かる。

## 版（バージョン）の確認

楽曲リストの一番下に `版 2026-11-03 17:04` のように出る。
開いたときにも一度だけ画面の下に出るので、**差し替えたかどうかがすぐ分かる**。

## 読み込み済みの曲を整理し直す

楽曲リストの一番下「読み込み済みの曲を整理し直す」から。

**コードの読み取り（スラッシュ・括弧・桁のずれ）は、ここを押さなくても直っている。**
譜面の文字そのものはアプリが書き換えないので、開けばそのまま新しい読み方で表示される。

ここで直せるのは**欄のほう**だけ。

- 本文に残っている曲名・作詞作曲・Key/Capo の行を欄に移す
- 空の欄（アーティスト・カポ・テンポ・キー）を譜面から埋める
- **カポ付きなのにキーの欄が押さえ方のままの曲**を、鳴る音のキーに直す

3つめは、以前のバージョンがキーを譜面のコードから推測していたせいで起きる。
たとえば「カポ3・譜面は D・本当は F の曲」のキー欄が D になっている、というもの。
何度かけても二重には上がらない。

## すべての曲を消すとき

クラウド側の削除は **80件ずつ**に分けて送る。失敗した分は入れ直して3回まで試し、
最後にサーバーへ聞いて本当に空になったか確かめる。

消し終わるまで同期の受け取りを止めるので、消しかけの状態が戻ってくることはない。
それでも残ってしまった場合は「○曲が消しきれませんでした」と件数を出すので、
もう一度「すべて消す」を押せばよい。「すべて消しました」と出たときは本当に空になっている。

選んだ曲の削除も同じやり方で送る。

## データの保存先

曲のデータはブラウザの中に保存される。**ブラウザの履歴やサイトデータを消すと
一緒に消えるので、大事な曲は「書き出し」でファイルに残しておくこと。**

- 曲ごと … 曲画面の「書き出し」→ `.md` ファイル
- フォルダごと … 楽曲リストのフォルダ見出しの「このフォルダを書き出す」→ `.zip`

書き出した `.md` は、そのまま読み込み直せる。

## 歌詞の文字起こし

別途入れた Faster-Whisper-XXL を使う。

```powershell
$ex = "$HOME\apps\Faster-Whisper-XXL_r245.4_windows\Faster-Whisper-XXL\faster-whisper-xxl.exe"
& $ex "音源.mp3" -l ja -m large-v2 -o . -pp -f all
```

出てきた `.srt` から歌詞だけ取り出す（文字コードの指定を忘れないこと）:

```powershell
$p = "曲名"
$lines = Get-Content "$p.srt" -Encoding UTF8 | Where-Object { $_ -notmatch '^\d+$' -and $_ -notmatch '-->' -and $_.Trim() -ne '' } | ForEach-Object { ($_ -replace [char]0x266A, '').Trim() }
[System.IO.File]::WriteAllLines("$p.txt", $lines, [System.Text.UTF8Encoding]::new($true))
```

## 作り直すとき・直すとき

`index.html` の中は上から順にこうなっている。

- 0章 … 音源の解析エンジン（FFT・クロマ・テンポ・キー・コード推定）
- 1章 … コード譜テキストの正規化とパーサー
- 2章 … 移調
- 3章 … コードダイアグラム
- 4章 … サンプル曲
- 5章以降 … 画面の描画と操作

一番壊しやすいのは**文字幅の計算**(`charWidth` / `colToPx`)。
日本語は半角の2文字分の幅があるので、コード位置を文字数で数えると歌詞とずれる。
canvas で実際の幅を測ってピクセル位置を出しているので、ここは触らないこと。
