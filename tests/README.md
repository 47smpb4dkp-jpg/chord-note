# テスト

コード譜ノートのテスト 40 本。**本物の `index.html` をブラウザで開いて、中の関数を直接呼ぶ**つくり。モックは使っていない（Firebase とドライブの通信だけ、テスト側で差し替える）。

## 流し方

```bash
./tests/run-all.sh                 # 全部（3〜5分）
./tests/run-all.sh tcapo tkey      # 名前に含む文字列で絞る
node tests/rules.js                # 1本だけ（5秒）
./tests/run-all.sh --accept        # いまの出力を「正解」として保存し直す
```

必要なもの：`node` と `playwright`。入っていなければ run-all.sh が入れ方を教えてくれる。

**`tplays.js` と `tstor.js` の2本は HTTP サーバーが必要**（`localhost:8899`）。`run-all.sh` が
自動で立てて片付けるので、全部流すときは何もしなくてよい。この2本だけ単体で流すときは、先に
リポジトリのルートで `python3 -m http.server 8899 &` を動かしておく。立てずに流すと
`ERR_CONNECTION_REFUSED` で落ちる（残り38本は `file://` で開くので不要）。
各テストの出力は `tests/.log/<名前>.txt` に残る（git には入れない）。

## 直したあとに必ず流すもの

```bash
node tests/rules.js
```

**機能どうしの干渉チェック 71 項目（A〜O）。5秒で終わる。** 何を直してもこれは流す。
デプロイの前に `./tests/run-all.sh` で全部流す。

## 合否のつけ方 — 前回の出力と比べる

**正解は `tests/golden/<名前>.txt` に入っていて、git で管理している。**
テストを流すと出力をそれと比べ、**1文字でも違えば NG にする。**

これがないと困るのは、**落ちないけれど中身が違う**間違い。
歌詞が1行消える、キーが1つずれる、コードの位置がずれる——アプリは平気な顔で動くので、
エラーでは分からない。出力を突き合わせて初めて見える。

毎回変わるのが当たり前のもの（時刻・アプリの版・録画のバイト数など）は
`_normalize.py` で伏せてから比べる。**伏せる対象を増やすときは慎重に。伏せすぎると本当の間違いも見えなくなる。**
2026-11-24 に40本を2回流して実測し、ばらついたのは次の5種類だけだった。

- 時刻（`2026-11-24T11:50:43Z` / `2026/11/24 20:50:43` / `11/24 20:48`）
- アプリの版（`V261122-16`）
- 1970年からのミリ秒（`1795520990953`）
- ファイル名の日時印（`朝_261124-2050.mp4`）
- 録画のバイト数（エンコーダの出力なので毎回わずかに違う）

### 差分が出たとき

意図した変更なら、**画面に出る差分を読んで、それが望んだ変化であることを確かめてから**更新する。

```bash
./tests/run-all.sh --accept        # 全部
./tests/run-all.sh --accept tcapo  # 絞って
git diff tests/golden              # 何が変わったか確かめる
```

**中身を見ずに `--accept` を打つと、間違った出力が新しい正解になり、この仕組みが死ぬ。**
更新した差分は git のコミットに残るので、後から「この変更で何が変わったか」を追える。

### この仕組みで分かること・分からないこと

**分かる**のは「**前回と振る舞いが変わった**」こと。
**分からない**のは「**そもそもテストが見ていないこと**」。

正解と比べる仕組みは、テストが見ている範囲の中でしか効かない。
2026-11-24 に実測したところ、**小節線の折り返し（4本ごと）とコードのうしろの余白は、どのテストも
見ていなかった**（わざと壊しても40本全部通ってしまった）。これは `rules.js` の【N】を足して埋めた。

→ **機能を足したら、必ず `rules.js` に検証を足す。** 正解ファイルは見落としを埋めてくれない。

## 書き足すとき

1. **機能を足したら `rules.js` に検証を足す。** 干渉はここで止める
2. 新しいテストは `tests/` に `t〇〇.js` で置く。`run-all.sh` が勝手に拾う
3. アプリは `__dirname + '/../index.html'` で開く（リポジトリのルートにある）
4. 通信が必要なら `http://localhost:8899/index.html`（run-all.sh がサーバーを立てる）
5. **できれば終了コードで合否を出す**（`process.exit(落ちた件数 ? 1 : 0)`）。そうすれば run-all.sh が自動で判定できる
